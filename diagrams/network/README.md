# Network diagrams

The [network topology and traffic paths](topology.md) diagram shows the public architectural view. A smaller version and operating notes live in the [network design](../../docs/network-setup.md).

If another network diagram is added here, include:

- editable source and rendered export
- trust-zone role without publishing operational identifiers
- routed and trust boundaries
- management paths
- only the addresses that are safe and useful to publish
- a date or commit that ties it to the configuration

Physical cabling, complete address inventories, and sensitive management details should remain in the appropriate private system of record.
