    VOICEVOX setup
  • Install VOICEVOX from voicevox.hiroshiba.jp and start it — its engine listens on localhost:50021.
  • Serve this page from localhost so the engine accepts requests: run python3 -m http.server 8000 in the folder with this file, then open http://localhost:8000/wanikani_listening_practice.html.
  • If Connect fails from a file:// page, open the engine's settings at 127.0.0.1:50021/setting and set CORS Policy Mode to all (or launch the engine with --cors_policy_mode all).
  • Click Connect, pick a speaker, then Test voice.

    • Voice quality depends on your browser/OS. Microsoft Edge has excellent natural Japanese voices; Chrome's "Google 日本語" is good too. On macOS you can add voices in System Settings → Accessibility → Spoken Content.
